# Bibliotheca Illustration Studio

Локально управляемая редакторская студия для создания, обработки и публикации иллюстраций к литературным произведениям.

Демо-интерфейс: [bibliotheca-studio](https://chearu-stack.github.io/bibliotheca-studio/)

## Назначение

Студия связывает литературный архив с рабочим процессом иллюстратора:

```text
произведение → промпт → генерация → обработка → предпросмотр → утверждение → публикация
```

Интерфейс размещён на GitHub Pages, а доступ к произведениям, локальным файлам, API-ключам и Git выполняется через локальный сервер на компьютере редактора.

## Возможности

- фильтрация произведений по прозе и поэзии;
- поиск по названию произведения;
- генерация промпта на основе текста произведения;
- ручное редактирование промпта перед генерацией;
- генерация изображения через локальный backend;
- прикрепление собственного PNG, JPG или WEBP;
- жёсткий итоговый формат `1024×768 PNG`;
- графитовый штрихованный холст для изображений меньшего размера;
- локальные пресеты «Чёрно-белое» и «Карандаш / графит / уголь»;
- автоматическая загрузка существующей иллюстрации при выборе произведения;
- очистка временного предпросмотра без удаления утверждённого изображения;
- двойное подтверждение перед необратимой заменой файла;
- сборка сайта и публикация утверждённого результата через Git.

## Архитектура

```text
GitHub Pages
  публичный HTML-интерфейс студии
          ↓ CORS-запросы
Локальный studio_server.py
  content/ · assets/ · .env · DeepSeek · Pollinations · Git
```

Публичный репозиторий не содержит API-ключей, `.env` или серверного кода. Без запущенного локального backend интерфейс открывается, но операции с произведениями и изображениями недоступны.

## Локальный запуск

В основном репозитории библиотеки запустите:

```text
tools/start_studio.bat
```

Батник запускает локальный сервер и открывает опубликованный интерфейс студии автоматически.

## Безопасность

- API-ключи хранятся только локально;
- секреты не добавляются в Git;
- сервер слушает только `127.0.0.1`;
- неподтверждённые изображения остаются во временном хранилище;
- существующие иллюстрации заменяются только после двух подтверждений.

## Статус

Проект подготовлен как независимый редакторский модуль, который может работать с библиотекой Чернышева и в дальнейшем адаптироваться для других литературных архивов.
